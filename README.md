# Dealroom API
`./dealroom.sh` loads `.env`, refreshes the token when needed, and lists the 10 highest-valued VC-backed companies founded since 2020.
Credentials are in `.env`. Never commit or paste the client secret.
Tokens last 24 hours; the script fetches a fresh one when needed.
Setup: https://developers.beta.dealroom.co/getting-started/agent-setup.md
Docs: https://developers.beta.dealroom.co/llms.txt
Counts, rankings, and charts follow apis/dealroom-api-analysis.md.
Read README.md in this folder and continue from there.
